# Network Security Threats Report

## Introduction
Network security threats are harmful activities that attempt to damage, disrupt, or gain unauthorized access to computer networks and systems.

## Denial of Service (DoS) Attack
### How it Works
A DoS attack floods a server or network with excessive traffic, making services unavailable to users.

### Impact
- Website downtime
- Resource exhaustion
- Financial losses

### Prevention
- Firewalls
- Traffic filtering
- Intrusion Detection Systems

---

## Man-in-the-Middle (MITM) Attack
### How it Works
An attacker secretly intercepts communication between two parties.

### Impact
- Data theft
- Password leakage
- Unauthorized access

### Prevention
- HTTPS
- VPN
- Encryption

---

## Spoofing Attack
### How it Works
Attackers impersonate trusted devices or users using fake IP or email addresses.

### Impact
- Unauthorized access
- Data manipulation
- Malware spread

### Prevention
- Authentication methods
- Packet filtering
- Anti-spoofing tools

---

## Real-World Examples
- Mirai Botnet Attack
- Equifax Data Breach

---

## Conclusion
Organizations must regularly monitor networks, apply security controls, and educate users to reduce cybersecurity risks.
